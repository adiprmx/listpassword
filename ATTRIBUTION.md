# Atribusi

Bahan dasar daftar password di repo ini berasal dari SecLists:

- SecLists, https://github.com/danielmiessler/SecLists, lisensi MIT
- Pembuat: Daniel Miessler, Jason Haddix, Ignacio Portal, g0tmi1k, dan kontributor lainnya

Yang dibuat sendiri di repo ini (bukan dari SecLists):

- Struktur repo ini (fokus ke satu file `listpassword.txt`, bukan tiruan struktur SecLists)
- Skrip `build-listpassword.py` (gabung, bersih, dedup dengan urutan frekuensi)
- Paket turunan `packs/` dan file utama `listpassword.txt` sebagai hasil olahan dari sumber di atas
- Dokumentasi berbahasa Indonesia di `README.md` dan `docs/`

Repo ini bukan proyek resmi SecLists, bukan fork resmi, dan tidak berafiliasi dengan pembuat SecLists. Kalau lo mau katalog lengkapnya, langsung ke repo SecLists di atas.
